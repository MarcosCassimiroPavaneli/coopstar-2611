# 🚀 Coopstar Express — Serviços de Moto Frete

![Coopstar Express Logo](public/images/logo.png)

Website moderno e de alta performance para a **Coopstar Express**, empresa especializada em serviços de entregas rápidas, coletas e moto frete com atendimento 24 horas em São Paulo e Grande São Paulo.

---

## 🌟 Destaques do Projeto

- **Design Moderno & Responsivo**: Interface elegante desenvolvida em React, TypeScript e Tailwind CSS com animações fluidas (Framer Motion).
- **Banner Hero Interativo**: Carrossel automático com suporte a gestos e transições suaves.
- **Seção de Serviços**: Apresentação clara de Moto Frete, Delivery Empresarial e Entregas fora da Capital com selos oficiais da marca.
- **Tabela de Preços**: Visualização transparente de tarifas por região.
- **Atendimento 24/7**: Formulário de contato dinâmico e integração direta com WhatsApp e telefone.
- **Imagens em Altíssima Resolução**: Fotografias realistas otimizadas nos formatos WebP e AVIF com marca d'água oficial padronizada.

---

## 🛠️ Tecnologias Utilizadas

- [React 18](https://react.dev/) — Biblioteca UI

- [Vite](https://vitejs.dev/) — Build tool rápido para desenvolvimento web

- [Framer Motion](https://www.framer.com/motion/) — Animações e micro-interações
- [Lucide React](https://lucide.dev/) — Ícones vetoriais modernos

## 🚀 Como Executar o Projeto Localmente

### Pré-requisitos
- [Node.js](https://nodejs.org/) (versão 18 ou superior)
- `npm` ou `yarn`

### Passo a passo

1. **Clonar o repositório:**
   ```bash
   git clone https://github.com/MarcosCassimiroPavaneli/coopstar-2611.git
   cd coopstar-2611
   ```

2. **Instalar as dependências:**
   ```bash
   npm install
   ```

3. **Iniciar o servidor de desenvolvimento:**
   ```bash
   npm run dev
   ```
   Acesse a aplicação no navegador em: `http://localhost:8000/` (ou na porta configurada pelo Vite).

4. **Gerar a versão de produção (Build):**
   ```bash
   npm run build
   ```
